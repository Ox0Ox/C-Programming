## Introduction to C Programming

C is a general-purpose, procedural computer programming language developed in the early 1970s by Dennis Ritchie at Bell Labs. It was designed to be a language that was both efficient and flexible, allowing close control over hardware resources while maintaining portability.

### Key Features of C
- **Mid-level language**: Combines elements of both high-level and low-level languages
- **Portability**: Code written in C can be compiled for different platforms with minimal changes
- **Efficiency**: Provides access to memory manipulation and hardware control
- **Modularity**: Supports structured programming through functions
- **Rich library support**: Comes with standard libraries for common operations
- **Foundation for other languages**: Many modern languages like C++, Java, and Python have drawn syntax and concepts from C

### Why C Remains Relevant
Despite being several decades old, C continues to be widely used for:
- Operating systems development
- Embedded systems programming
- System utilities
- Performance-critical applications
- Legacy system maintenance
- Foundation for learning programming concepts

### C's Role in Modern AI

- **AI frameworks**: Many AI libraries have C backends (e.g., TensorFlow's core operations)
- **System-level AI integration**: Integrating AI capabilities into operating systems and low-level software

### Examples of C in AI Contexts
- Optimized matrix operations in deep learning libraries

- Kernel-level integration of AI capabilities

## Program Structure, Characteristics and Errors

### Basic Structure of a C Program

Every C program follows a basic structure:

```c
/* Preprocessor directives */
#include <stdio.h>

/* Function declarations or prototypes (if any) */
double calculateArea(double radius);

/* Global variables (if any) */
const double PI = 3.14159;

/* Main function - program execution starts here */
int main() {
    /* Local variable declarations */
    double radius = 5.0;
    double area;
    
    /* Statements and expressions */
    area = calculateArea(radius);
    printf("Area of circle with radius %.2f is %.2f\n", radius, area);
    
    /* Return statement */
    return 0;
}

/* Function definitions */
double calculateArea(double radius) {
    return PI * radius * radius;
}
```

### Key Components of a C Program

1. **Preprocessor Directives**: Instructions to the compiler before actual compilation begins
   - Include files: `#include <header_file.h>`
   - Macro definitions: `#define PI 3.14159`
   - Conditional compilation: `#ifdef`, `#ifndef`, `#endif`

2. **Functions**: Building blocks of a C program
   - Every program must have a `main()` function where execution begins
   - Each function has a return type, name, parameters, and body

3. **Variables**: Named storage for data
   - Must be declared before use
   - Can be local (inside functions) or global (outside functions)

4. **Statements**: Instructions that perform actions
   - Assignment statements
   - Function calls
   - Control statements
   - Each statement typically ends with a semicolon

### Common Errors in C Programming

1. **Syntax Errors**: Detected during compilation
   - Missing semicolons
   - Undeclared variables
   - Mismatched parentheses or braces
   - Example:
     ```c
     int main() {
         printf("Hello, world!\n")  // Missing semicolon
         return 0;
     }
     ```

2. **Semantic Errors**: Logical errors that don't violate syntax
   - Using uninitialized variables
   - Type mismatches in assignments
   - Off-by-one errors in loops
   - Example:
     ```c
     int main() {
         int sum = 0;
         // Should be i <= 10 to include 10
         for(int i = 1; i < 10; i++) {
             sum += i;
         }
         printf("Sum from 1 to 10: %d\n", sum);
         return 0;
     }
     ```

3. **Runtime Errors**: Occur during program execution
   - Division by zero
   - Memory access violations
   - Stack overflow
   - Example:
     ```c
     int main() {
         int a = 10;
         int b = 0;
         int result = a / b;  // Division by zero - runtime error
         printf("Result: %d\n", result);
         return 0;
     }
     ```

4. **Linker Errors**: Occur when the linker can't resolve references
   - Undefined references to functions
   - Multiple definitions of functions or variables
   - Example:
     ```c
     // In main.c
     int main() {
         int result = calculate(10);  // Function is declared but not defined
         printf("Result: %d\n", result);
         return 0;
     }
     
     // No implementation of calculate() function
     ```

### Compilation Process in C

The process of converting C source code to an executable involves four main steps:

1. **Preprocessing**: Handling all preprocessor directives
   - Includes header files
   - Expands macros
   - Removes comments

2. **Compilation**: Converting preprocessed code to assembly code
   - Checks syntax
   - Generates assembly instructions

3. **Assembly**: Converting assembly code to object code
   - Generates machine code in object files

4. **Linking**: Combining object files into an executable
   - Resolves references between files
   - Includes code from libraries

## Output Functions

C provides several ways to display output to the user, primarily through the functions defined in the `stdio.h` header file.

### The `printf()` Function

The most commonly used output function is `printf()`, which allows formatted output:

```c
#include <stdio.h>

int main() {
    printf("Hello, world!\n");  // Simple string output
    
    int age = 25;
    printf("I am %d years old.\n", age);  // Integer output
    
    float height = 5.9;
    printf("My height is %.1f feet.\n", height);  // Float output with precision
    
    char grade = 'A';
    printf("I got %c grade in programming.\n", grade);  // Character output
    
    char name[] = "John";
    printf("My name is %s.\n", name);  // String output
    
    printf("Multiple values: %d, %.2f, %c\n", age, height, grade);  // Multiple values
    
    return 0;
}
```

### Format Specifiers

Format specifiers allow you to format different data types in the output:

| Specifier | Data Type          | Example                                  |
|-----------|--------------------|-----------------------------------------|
| `%d`, `%i`| Integer            | `printf("%d", 42);`                     |
| `%f`      | Float/Double       | `printf("%f", 3.14);`                   |
| `%e`, `%E`| Scientific notation| `printf("%e", 3000000.0);` → 3.000000e+06 |
| `%c`      | Character          | `printf("%c", 'A');`                    |
| `%s`      | String             | `printf("%s", "Hello");`                |
| `%x`, `%X`| Hexadecimal        | `printf("%x", 255);` → ff               |
| `%o`      | Octal              | `printf("%o", 64);` → 100               |
| `%p`      | Pointer address    | `printf("%p", &variable);`              |
| `%u`      | Unsigned integer   | `printf("%u", 42);`                     |
| `%%`      | Percent sign       | `printf("50%%");` → 50%                 |

### Format Specifier Modifiers

You can modify format specifiers to control the output format:

1. **Field Width**:
   ```c
   printf("%5d", 42);    // Output: "   42" (right-aligned)
   printf("%-5d", 42);   // Output: "42   " (left-aligned)
   ```

2. **Precision**:
   ```c
   printf("%.2f", 3.14159);  // Output: "3.14"
   printf("%.4s", "Hello");  // Output: "Hell" (first 4 characters)
   ```

3. **Combining Width and Precision**:
   ```c
   printf("%7.2f", 3.14159);  // Output: "   3.14" (7 characters wide)
   ```

4. **Zero Padding**:
   ```c
   printf("%05d", 42);  // Output: "00042"
   ```

### Other Output Functions

1. **`puts()`**: Outputs a string followed by a newline
   ```c
   puts("Hello, world!");  // Simpler than printf(), automatically adds newline
   ```

2. **`putchar()`**: Outputs a single character
   ```c
   putchar('A');  // Outputs the character 'A'
   ```

3. **`fprintf()`**: Prints formatted output to a file
   ```c
   FILE *file = fopen("output.txt", "w");
   fprintf(file, "Value: %d\n", 42);
   fclose(file);
   ```

### Example: Formatted Table Output

```c
#include <stdio.h>

int main() {
    printf("%-15s %-10s %-10s\n", "Name", "Age", "Height");
    printf("%-15s %-10d %-10.2f\n", "John Smith", 25, 5.11);
    printf("%-15s %-10d %-10.2f\n", "Jane Doe", 28, 5.6);
    printf("%-15s %-10d %-10.2f\n", "Bob Johnson", 32, 6.2);
    
    return 0;
}
```

Output:
```
Name            Age        Height    
John Smith      25         5.11      
Jane Doe        28         5.60      
Bob Johnson     32         6.20      
```

## Variables and Data Types

Variables are named storage locations in memory that hold values which can be modified during program execution. C requires all variables to be declared with their data type before they can be used.

### Variable Declaration and Initialization

```c
// Declaration
data_type variable_name;

// Declaration with initialization
data_type variable_name = initial_value;

// Multiple declarations
data_type variable1, variable2, variable3;
```

Example:
```c
#include <stdio.h>

int main() {
    // Declaration
    int age;
    
    // Initialization after declaration
    age = 25;
    
    // Declaration with initialization
    float salary = 50000.50;
    
    // Multiple variables
    char grade = 'A', section = 'B';
    
    printf("Age: %d\n", age);
    printf("Salary: $%.2f\n", salary);
    printf("Grade: %c, Section: %c\n", grade, section);
    
    return 0;
}
```

### Fundamental Data Types in C

| Data Type | Description | Format Specifier | Typical Size | Example |
|-----------|-------------|------------------|--------------|---------|
| `int` | Integer numbers | `%d`, `%i` | 4 bytes | `int count = 42;` |
| `char` | Single character | `%c` | 1 byte | `char grade = 'A';` |
| `float` | Single-precision floating-point | `%f` | 4 bytes | `float price = 9.99;` |
| `double` | Double-precision floating-point | `%lf` | 8 bytes | `double pi = 3.14159265359;` |
| `_Bool` | Boolean value (0 or 1) | `%d` | 1 byte | `_Bool flag = 1;` |

### Type Modifiers

C provides modifiers to alter the range or precision of basic data types:

1. **Size Modifiers**:
   - `short` - smaller integer (typically 2 bytes)
   - `long` - larger integer (typically 4 or 8 bytes)
   - `long long` - even larger integer (typically 8 bytes)

2. **Sign Modifiers**:
   - `signed` - can represent negative and positive numbers (default)
   - `unsigned` - can only represent non-negative numbers

Examples:
```c
unsigned int positive_number = 50000;
long int large_number = 2000000000;
short int small_number = 32000;
unsigned long int very_large_positive = 4000000000;
```

### Memory Sizes and Ranges

The exact size of data types can vary by platform. The `sizeof` operator can be used to determine the size:

```c
#include <stdio.h>

int main() {
    printf("Size of char: %zu bytes\n", sizeof(char));
    printf("Size of int: %zu bytes\n", sizeof(int));
    printf("Size of float: %zu bytes\n", sizeof(float));
    printf("Size of double: %zu bytes\n", sizeof(double));
    
    return 0;
}
```

Typical ranges:
- `char`: -128 to 127 or 0 to 255 (unsigned)
- `int`: -2,147,483,648 to 2,147,483,647
- `unsigned int`: 0 to 4,294,967,295
- `float`: 1.2E-38 to 3.4E+38 (6-7 significant digits)
- `double`: 2.3E-308 to 1.7E+308 (15-16 significant digits)

### Derived Data Types

#### Arrays

Arrays store multiple items of the same type:

```c
int scores[5] = {95, 88, 76, 90, 82};  // Array of 5 integers
char name[10] = "John";                // Character array (string)

// Accessing array elements (zero-indexed)
printf("First score: %d\n", scores[0]);  // Output: 95
printf("Name: %s\n", name);              // Output: John
```

#### Derived from Basic Types

1. **Arrays**: Multiple elements of same type
   ```c
   int numbers[5] = {1, 2, 3, 4, 5};
   ```

2. **Pointers**: Variables that store memory addresses
   ```c
   int *ptr;       // Pointer to an integer
   int num = 10;
   ptr = &num;     // Store address of num in ptr
   ```

3. **Structures**: Group related variables of different types
   ```c
   struct Student {
       char name[50];
       int age;
       float gpa;
   };
   
   struct Student student1 = {"Alice", 20, 3.8};
   ```

4. **Unions**: Store different data types in the same memory location
   ```c
   union Data {
       int i;
       float f;
       char str[20];
   };
   
   union Data data;
   data.i = 10;    // Data now holds an integer
   ```

5. **Enumerations**: User-defined type consisting of integral constants
   ```c
   enum Days {MON, TUE, WED, THU, FRI, SAT, SUN};
   enum Days today = WED;
   ```

### Type Conversion

C allows conversion between different data types:

1. **Implicit Conversion (Automatic)**:
   ```c
   int i = 10;
   float f = i;    // int converted to float (f = 10.0)
   ```

2. **Explicit Conversion (Casting)**:
   ```c
   float f = 3.14;
   int i = (int)f;  // Explicitly convert float to int (i = 3)
   ```

### Constants

Constants are values that cannot be modified after declaration:

1. **Using `const` qualifier**:
   ```c
   const float PI = 3.14159;
   ```

2. **Using `#define` directive**:
   ```c
   #define MAX_SIZE 100
   ```

### Example: Using Various Data Types

```c
#include <stdio.h>

int main() {
    // Basic types
    int students = 30;
    float average_score = 85.6;
    char section = 'B';
    double exact_pi = 3.1415926535897932;
    
    // Modified types
    unsigned int total_population = 8000000;
    long int national_debt = 21000000000;
    
    // Array
    int top_scores[3] = {98, 97, 95};
    
    // Constant
    const int DAYS_IN_WEEK = 7;
    
    // Output
    printf("Class %c has %d students with average score %.1f\n", 
           section, students, average_score);
    printf("Pi to 15 decimal places: %.15f\n", exact_pi);
    printf("Country population: %u\n", total_population);
    printf("National debt: %ld\n", national_debt);
    printf("Top score: %d\n", top_scores[0]);
    printf("Days in a week: %d (this cannot be changed)\n", DAYS_IN_WEEK);
    
    return 0;
}
```

## Input Functions, Range of Values, and Qualifiers

Input functions allow programs to receive data from users. The primary input functions in C are defined in the `stdio.h` header.

### Basic Input Functions

#### 1. `scanf()` Function

The `scanf()` function reads formatted input from the standard input (keyboard):

```c
#include <stdio.h>

int main() {
    int age;
    printf("Enter your age: ");
    scanf("%d", &age);  // Note the & operator to get the address
    
    printf("You entered: %d\n", age);
    return 0;
}
```

#### Format Specifiers for `scanf()`

The format specifiers used with `scanf()` are similar to those used with `printf()`:

| Specifier | Data Type          | Example                       |
|-----------|--------------------|-------------------------------|
| `%d`, `%i`| Integer            | `scanf("%d", &num);`          |
| `%f`      | Float              | `scanf("%f", &price);`        |
| `%lf`     | Double             | `scanf("%lf", &pi);`          |
| `%c`      | Character          | `scanf("%c", &letter);`       |
| `%s`      | String             | `scanf("%s", name);`          |
| `%x`, `%X`| Hexadecimal        | `scanf("%x", &hex_value);`    |
| `%o`      | Octal              | `scanf("%o", &oct_value);`    |
| `%u`      | Unsigned integer   | `scanf("%u", &u_num);`        |

#### Reading Multiple Values

You can read multiple values in a single `scanf()` call:

```c
#include <stdio.h>

int main() {
    int id;
    float salary;
    
    printf("Enter ID and salary: ");
    scanf("%d %f", &id, &salary);
    
    printf("ID: %d, Salary: $%.2f\n", id, salary);
    return 0;
}
```

#### Common Issues with `scanf()`

1. **Buffer Issues**: `scanf()` leaves the newline character in the input buffer, which can affect subsequent reads
2. **String Input**: `scanf("%s", str)` stops at whitespace
3. **Format Mismatches**: Entering wrong data type causes unpredictable behavior

Example showing buffer problem:
```c
#include <stdio.h>

int main() {
    int age;
    char name[50];
    
    printf("Enter age: ");
    scanf("%d", &age);
    
    // The newline from previous input remains in buffer
    printf("Enter name: ");
    scanf("%s", name);
    
    printf("Age: %d, Name: %s\n", age, name);
    return 0;
}
```

Solution:
```c
#include <stdio.h>

int main() {
    int age;
    char name[50];
    
    printf("Enter age: ");
    scanf("%d", &age);
    
    // Clear input buffer
    while (getchar() != '\n');
    
    printf("Enter name: ");
    scanf("%s", name);
    
    printf("Age: %d, Name: %s\n", age, name);
    return 0;
}
```

### Type Qualifiers

Type qualifiers modify the behavior of variables:

#### 1. `const` Qualifier

Makes a variable immutable (read-only):

```c
const int MAX_USERS = 100;
// MAX_USERS = 200;  // Error: assignment of read-only variable
```

#### 2. `volatile` Qualifier

Tells the compiler that a variable's value may change unexpectedly:

```c
volatile int sensor_reading;  // Value might change due to hardware
```

#### 3. `restrict` Qualifier (C99 and later)

Informs the compiler that a pointer is the only means to access an object:

```c
void copy(int * restrict dest, int * restrict src, int size) {
    for (int i = 0; i < size; i++) {
        dest[i] = src[i];
    }
}
```

#### 3. Input Validation Example

```c
#include <stdio.h>

int main() {
    int age;
    int valid_input = 0;
    
    do {
        printf("Enter your age (1-120): ");
        if (scanf("%d", &age) == 1) {
            if (age >= 1 && age <= 120) {
                valid_input = 1;
            } else {
                printf("Age must be between 1 and 120.\n");
            }
        } else {
            printf("Invalid input. Please enter a number.\n");
            while (getchar() != '\n');  // Clear input buffer
        }
    } while (!valid_input);
    
    printf("Your age is: %d\n", age);
    return 0;
}
```

### Example: Using Input, Types, and Ranges Together

The following program reads student information and validates the input based on acceptable ranges:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// Constants (qualifiers example)
const int MIN_AGE = 16;
const int MAX_AGE = 60;
const float MIN_GPA = 0.0;
const float MAX_GPA = 4.0;

int main() {
    char name[50];
    int age;
    float gpa;
    int valid_input = 0;
    
    // Get and validate name
    printf("Enter student name: ");
    fgets(name, 50, stdin);
    
    // Remove trailing newline from fgets
    name[strcspn(name, "\n")] = 0;
    
    // Get and validate age
    do {
        printf("Enter student age (%d-%d): ", MIN_AGE, MAX_AGE);
        if (scanf("%d", &age) == 1) {
            if (age >= MIN_AGE && age <= MAX_AGE) {
                valid_input = 1;
            } else {
                printf("Age must be between %d and %d.\n", MIN_AGE, MAX_AGE);
            }
        } else {
            printf("Invalid input. Please enter a number.\n");
            while (getchar() != '\n');  // Clear input buffer
        }
    } while (!valid_input);
    
    // Clear input buffer
    while (getchar() != '\n');
    
    // Reset valid_input flag
    valid_input = 0;
    
    // Get and validate GPA
    do {
        printf("Enter student GPA (%.1f-%.1f): ", MIN_GPA, MAX_GPA);
        if (scanf("%f", &gpa) == 1) {
            if (gpa >= MIN_GPA && gpa <= MAX_GPA) {
                valid_input = 1;
            } else {
                printf("GPA must be between %.1f and %.1f.\n", MIN_GPA, MAX_GPA);
            }
        } else {
            printf("Invalid input. Please enter a number.\n");
            while (getchar() != '\n');  // Clear input buffer
        }
    } while (!valid_input);
    
    // Display student information
    printf("\nStudent Information:\n");
    printf("-------------------\n");
    printf("Name: %s\n", name);
    printf("Age: %d\n", age);
    printf("GPA: %.2f\n", gpa);
    
    return 0;
}
```

- Using constants (`const` qualifier)
- Reading different types of input
- Validating input based on acceptable ranges
- Handling input errors
- Clearing the input buffer to prevent issues
