## Introduction to C Programming
C is a general-purpose, procedural computer programming language developed in the early 1970s by Dennis Ritchie at Bell Labs. It was designed to be a language that was both efficient and flexible, allowing close control over hardware resources while maintaining portability.
### Key Features of C
- **Mid-level language**: Combines elements of both high-level and low-level languages
- **Portability**: Code written in C can be compiled for different platforms with minimal changes
- **Efficiency**: Provides access to memory manipulation and hardware control
- **Modularity**: Supports structured programming through functions
- **Rich library support**: Comes with standard libraries for common operations
- **Foundation for other languages**: Many modern languages like C++, Java, and Python have drawn syntax and concepts from C
### Why C Remains Relevant
Despite being several decades old, C continues to be widely used for:

- Operating systems development
- Embedded systems programming
- System utilities
- Performance-critical applications
- Legacy system maintenance
- Foundation for learning programming concepts
## C Programming in the Era of AI

- **AI frameworks**: Many AI libraries have C backends (e.g., TensorFlow's core operations)
- **System-level AI integration**: Integrating AI capabilities into operating systems and low-level software
### Examples of C in AI Contexts
- Optimized matrix operations in deep learning libraries

## Program Structure, Characteristics and Errors
### Basic Structure of a C Program
Every C program follows a basic structure:
~~~ c
/* Preprocessor directives */
#include <stdio.h>

/* Function declarations or prototypes (if any) */
double calculateArea(double radius);

/* Global variables (if any) */
const double PI = 3.14159;

/* Main function - program execution starts here */
int main() {
    /* Local variable declarations */
    double radius = 5.0;
    double area;
    
    /* Statements and expressions */
    area = calculateArea(radius);
    printf("Area of circle with radius %.2f is %.2f\n", radius, area);
    
    /* Return statement */
    return 0;
}

/* Function definitions */
double calculateArea(double radius) {
    return PI * radius * radius;
}
~~~
### Key Components of a C Program
1. **Preprocessor Directives**: Instructions to the compiler before actual compilation begins
   - Include files: `#include <header_file.h>`
   - Macro definitions: `#define PI 3.14159`
   - Conditional compilation: `#ifdef`, `#ifndef`, `#endif`
1. **Functions**: Building blocks of a C program
   - Every program must have a `main()` function where execution begins
   - Each function has a return type, name, parameters, and body
1. **Variables**: Named storage for data
   - Must be declared before use
   - Can be local (inside functions) or global (outside functions)
1. **Statements**: Instructions that perform actions
   - Assignment statements
   - Function calls
   - Control statements
   - Each statement typically ends with a semicolon
### Common Errors in C Programming
1. **Syntax Errors**: Detected during compilation
   - Missing semicolons
   - Undeclared variables
   - Mismatched parentheses or braces
   - Example:
     ~~~ c
     int main() {
         printf("Hello, world!\n")  // Missing semicolon
         return 0;
     }
     ~~~
1. **Semantic Errors**: Logical errors that don't violate syntax
   - Using uninitialized variables
   - Type mismatches in assignments
   - Off-by-one errors in loops
   - Example:
     ~~~ c
     int main() {
         int sum = 0;
         // Should be i <= 10 to include 10
         for(int i = 1; i < 10; i++) {
             sum += i;
         }
         printf("Sum from 1 to 10: %d\n", sum);
         return 0;
     }
     ~~~
1. **Runtime Errors**: Occur during program execution
   - Division by zero
   - Memory access violations
   - Stack overflow
   - Example:
     ~~~ c
     int main() {
         int a = 10;
         int b = 0;
         int result = a / b;  // Division by zero - runtime error
         printf("Result: %d\n", result);
         return 0;
     }
     ~~~
1. **Linker Errors**: Occur when the linker can't resolve references
   - Undefined references to functions
   - Multiple definitions of functions or variables
   - Example:
     ~~~ c
     // In main.c
     int main() {
         int result = calculate(10);  // Function is declared but not defined
         printf("Result: %d\n", result);
         return 0;
     }

     // No implementation of calculate() function
     ~~~
### Compilation Process in C
The process of converting C source code to an executable involves four main steps:

1. **Preprocessing**: Handling all preprocessor directives
   - Includes header files
   - Expands macros
   - Removes comments
1. **Compilation**: Converting preprocessed code to assembly code
   - Checks syntax
   - Generates assembly instructions
1. **Assembly**: Converting assembly code to object code
   - Generates machine code in object files
1. **Linking**: Combining object files into an executable
   - Resolves references between files
   - Includes code from libraries
## Output Functions
C provides several ways to display output to the user, primarily through the functions defined in the `stdio.h` header file.
### The `printf()` Function
The most commonly used output function is `printf()`, which allows formatted output:
~~~ c
#include <stdio.h>

int main() {
    printf("Hello, world!\n");  // Simple string output
    
    int age = 25;
    printf("I am %d years old.\n", age);  // Integer output
    
    float height = 5.9;
    printf("My height is %.1f feet.\n", height);  // Float output with precision
    
    char grade = 'A';
    printf("I got %c grade in programming.\n", grade);  // Character output
    
    char name[] = "John";
    printf("My name is %s.\n", name);  // String output
    
    printf("Multiple values: %d, %.2f, %c\n", age, height, grade);  // Multiple values
    
    return 0;
}
~~~
### Format Specifiers
Format specifiers allow you to format different data types in the output:

|Specifier|Data Type|Example|
| :-: | :-: | :-: |
|`%d`, `%i`|Integer|`printf("%d", 42);`|
|`%f`|Float/Double|`printf("%f", 3.14);`|
|`%e`, `%E`|Scientific notation|`printf("%e", 3000000.0);` → 3.000000e+06|
|`%c`|Character|`printf("%c", 'A');`|
|`%s`|String|`printf("%s", "Hello");`|
|`%x`, `%X`|Hexadecimal|`printf("%x", 255);` → ff|
|`%o`|Octal|`printf("%o", 64);` → 100|
|`%p`|Pointer address|`printf("%p", &variable);`|
|`%u`|Unsigned integer|`printf("%u", 42);`|
|`%%`|Percent sign|`printf("50%%");` → 50%|
### Format Specifier Modifiers
You can modify format specifiers to control the output format:

1. **Field Width**:
   ~~~ c
   printf("%5d", 42);    // Output: "   42" (right-aligned)
   printf("%-5d", 42);   // Output: "42   " (left-aligned)
   ~~~
1. **Precision**:
   ~~~ c
   printf("%.2f", 3.14159);  // Output: "3.14"
   printf("%.4s", "Hello");  // Output: "Hell" (first 4 characters)
   ~~~
1. **Combining Width and Precision**:
   ~~~ c
   printf("%7.2f", 3.14159);  // Output: "   3.14" (7 characters wide)
   ~~~
1. **Zero Padding**:
   ~~~ c
   printf("%05d", 42);  // Output: "00042"
   ~~~
### Other Output Functions
1. **`puts()`**: Outputs a string followed by a newline
   ~~~ c
   puts("Hello, world!");  // Simpler than printf(), automatically adds newline
   ~~~
1. **`putchar()`**: Outputs a single character
   ~~~ c
   putchar('A');  // Outputs the character 'A'
   ~~~
1. **`fprintf()`**: Prints formatted output to a file
   ~~~ c
   FILE *file = fopen("output.txt", "w");
   fprintf(file, "Value: %d\n", 42);
   fclose(file);
   ~~~
### Example: Formatted Table Output
~~~ c
#include <stdio.h>

int main() {
    printf("%-15s %-10s %-10s\n", "Name", "Age", "Height");
    printf("%-15s %-10d %-10.2f\n", "John Smith", 25, 5.11);
    printf("%-15s %-10d %-10.2f\n", "Jane Doe", 28, 5.6);
    printf("%-15s %-10d %-10.2f\n", "Bob Johnson", 32, 6.2);
    
    return 0;
}
~~~

Output:
~~~
Name            Age        Height    
John Smith      25         5.11      
Jane Doe        28         5.60      
Bob Johnson     32         6.20      
~~~
## Variables and Data Types
Variables are named storage locations in memory that hold values which can be modified during program execution. C requires all variables to be declared with their data type before they can be used.
### Variable Declaration and Initialization
~~~ c
// Declaration
data_type variable_name;

// Declaration with initialization
data_type variable_name = initial_value;

// Multiple declarations
data_type variable1, variable2, variable3;
~~~

Example:
~~~ c
#include <stdio.h>

int main() {
    // Declaration
    int age;
    
    // Initialization after declaration
    age = 25;
    
    // Declaration with initialization
    float salary = 50000.50;
    
    // Multiple variables
    char grade = 'A', section = 'B';
    
    printf("Age: %d\n", age);
    printf("Salary: $%.2f\n", salary);
    printf("Grade: %c, Section: %c\n", grade, section);
    
    return 0;
}
~~~
### Fundamental Data Types in C

|Data Type|Description|Format Specifier|Typical Size|Example|
| :-: | :-: | :-: | :-: | :-: |
|`int`|Integer numbers|`%d`, `%i`|4 bytes|`int count = 42;`|
|`char`|Single character|`%c`|1 byte|`char grade = 'A';`|
|`float`|Single-precision floating-point|`%f`|4 bytes|`float price = 9.99;`|
|`double`|Double-precision floating-point|`%lf`|8 bytes|`double pi = 3.14159265359;`|
|`_Bool`|Boolean value (0 or 1)|`%d`|1 byte|`_Bool flag = 1;`|
### Type Modifiers
C provides modifiers to alter the range or precision of basic data types:

1. **Size Modifiers**:
   - `short` - smaller integer (typically 2 bytes)
   - `long` - larger integer (typically 4 or 8 bytes)
   - `long long` - even larger integer (typically 8 bytes)
1. **Sign Modifiers**:
   - `signed` - can represent negative and positive numbers (default)
   - `unsigned` - can only represent non-negative numbers

Examples:
~~~ c
unsigned int positive_number = 50000;
long int large_number = 2000000000;
short int small_number = 32000;
unsigned long int very_large_positive = 4000000000;
~~~
### Memory Sizes and Ranges
The exact size of data types can vary by platform. The `sizeof` operator can be used to determine the size:
~~~ c
#include <stdio.h>

int main() {
    printf("Size of char: %zu bytes\n", sizeof(char));
    printf("Size of int: %zu bytes\n", sizeof(int));
    printf("Size of float: %zu bytes\n", sizeof(float));
    printf("Size of double: %zu bytes\n", sizeof(double));
    
    return 0;
}
~~~

Typical ranges:

- `char`: -128 to 127 or 0 to 255 (unsigned)
- `int`: -2,147,483,648 to 2,147,483,647
- `unsigned int`: 0 to 4,294,967,295
- `float`: 1.2E-38 to 3.4E+38 (6-7 significant digits)
- `double`: 2.3E-308 to 1.7E+308 (15-16 significant digits)
### Derived Data Types
#### Arrays
Arrays store multiple items of the same type:
~~~ c
int scores[5] = {95, 88, 76, 90, 82};  // Array of 5 integers
char name[10] = "John";                // Character array (string)

// Accessing array elements (zero-indexed)
printf("First score: %d\n", scores[0]);  // Output: 95
printf("Name: %s\n", name);              // Output: John
~~~
#### Derived from Basic Types
1. **Arrays**: Multiple elements of same type
   ~~~ c
   int numbers[5] = {1, 2, 3, 4, 5};
   ~~~
1. **Pointers**: Variables that store memory addresses
   ~~~ c
   int *ptr;       // Pointer to an integer
   int num = 10;
   ptr = &num;     // Store address of num in ptr
   ~~~
1. **Structures**: Group related variables of different types
   ~~~ c
   struct Student {
       char name[50];
       int age;
       float gpa;
   };

   struct Student student1 = {"Alice", 20, 3.8};
   ~~~
1. **Unions**: Store different data types in the same memory location
   ~~~ c
   union Data {
       int i;
       float f;
       char str[20];
   };

   union Data data;
   data.i = 10;    // Data now holds an integer
   ~~~
1. **Enumerations**: User-defined type consisting of integral constants
   ~~~ c
   enum Days {MON, TUE, WED, THU, FRI, SAT, SUN};
   enum Days today = WED;
   ~~~
### Type Conversion
C allows conversion between different data types:

1. **Implicit Conversion (Automatic)**:
   ~~~ c
   int i = 10;
   float f = i;    // int converted to float (f = 10.0)
   ~~~
1. **Explicit Conversion (Casting)**:
   ~~~ c
   float f = 3.14;
   int i = (int)f;  // Explicitly convert float to int (i = 3)
   ~~~
### Constants
Constants are values that cannot be modified after declaration:

1. **Using `const` qualifier**:
   ~~~ c
   const float PI = 3.14159;
   ~~~
1. **Using `#define` directive**:
   ~~~ c
   #define MAX_SIZE 100
   ~~~
### Example: Using Various Data Types
~~~ c
#include <stdio.h>

int main() {
    // Basic types
    int students = 30;
    float average_score = 85.6;
    char section = 'B';
    double exact_pi = 3.1415926535897932;
    
    // Modified types
    unsigned int total_population = 8000000;
    long int national_debt = 21000000000;
    
    // Array
    int top_scores[3] = {98, 97, 95};
    
    // Constant

    printf("Class %c has %d students with average score %.1f\n",

    printf("Country population: %u\n", total_population);
    printf("National debt: %ld\n", national_debt);
    printf("Top score: %d\n", top_scores[0]);
    printf("Days in a week: %d (this cannot be changed)\n", DAYS_IN_WEEK);
    
    return 0;
}
~~~
## Input Functions, Range of Values, and Qualifiers
Input functions allow programs to receive data from users. The primary input functions in C are defined in the `stdio.h` header.
### Basic Input Functions
#### 1\. `scanf()` Function
The `scanf()` function reads formatted input from the standard input (keyboard):
~~~ c
#include <stdio.h>

int main() {
    int age;
    printf("Enter your age: ");
    scanf("%d", &age);  // Note the & operator to get the address
    
    printf("You entered: %d\n", age);
    return 0;
}
~~~
#### Format Specifiers for `scanf()`
The format specifiers used with `scanf()` are similar to those used with `printf()`:

|Specifier|Data Type|Example|
| :-: | :-: | :-: |
|`%d`, `%i`|Integer|`scanf("%d", &num);`|
|`%f`|Float|`scanf("%f", &price);`|
|`%lf`|Double|`scanf("%lf", &pi);`|
|`%c`|Character|`scanf("%c", &letter);`|
|`%s`|String|`scanf("%s", name);`|
|`%x`, `%X`|Hexadecimal|`scanf("%x", &hex_value);`|
|`%o`|Octal|`scanf("%o", &oct_value);`|
|`%u`|Unsigned integer|`scanf("%u", &u_num);`|
#### Reading Multiple Values
You can read multiple values in a single `scanf()` call:
~~~ c
#include <stdio.h>

int main() {
    int id;
    float salary;
    
    printf("Enter ID and salary: ");
    scanf("%d %f", &id, &salary);
    
    printf("ID: %d, Salary: $%.2f\n", id, salary);
    return 0;
}
~~~
#### Common Issues with `scanf()`
1. **Buffer Issues**: `scanf()` leaves the newline character in the input buffer, which can affect subsequent reads
1. **String Input**: `scanf("%s", str)` stops at whitespace
1. **Format Mismatches**: Entering wrong data type causes unpredictable behavior

Example showing buffer problem:
~~~ c
#include <stdio.h>

int main() {
    int age;
    char name[50];
    
    printf("Enter age: ");
    scanf("%d", &age);
    
    // The newline from previous input remains in buffer
    printf("Enter name: ");
    scanf("%s", name);
    
    printf("Age: %d, Name: %s\n", age, name);
    return 0;
}
~~~

Solution:
~~~ c
#include <stdio.h>

int main() {
    int age;
    char name[50];
    
    printf("Enter age: ");
    scanf("%d", &age);
    
    // Clear input buffer
    while (getchar() != '\n');
    
    printf("Enter name: ");
    scanf("%s", name);
    
    printf("Age: %d, Name: %s\n", age, name);
    return 0;
}
~~~

### Type Qualifiers
Type qualifiers modify the behavior of variables:
#### 1\. `const` Qualifier
Makes a variable immutable (read-only):
~~~ c
const int MAX_USERS = 100;
// MAX_USERS = 200;  // Error: assignment of read-only variable
~~~
#### 2\. `volatile` Qualifier
Tells the compiler that a variable's value may change unexpectedly:
~~~ c
volatile int sensor_reading;  // Value might change due to hardware
~~~
#### 3\. `restrict` Qualifier (C99 and later)
Informs the compiler that a pointer is the only means to access an object:
~~~ c
void copy(int * restrict dest, int * restrict src, int size) {
    for (int i = 0; i < size; i++) {
        dest[i] = src[i];
    }
}
~~~

### Example: Using Input, Types, and Ranges Together
The following program reads student information and validates the input based on acceptable ranges:
~~~ c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// Constants (qualifiers example)
const int MIN_AGE = 16;
const int MAX_AGE = 60;
const float MIN_GPA = 0.0;
const float MAX_GPA = 4.0;

int main() {
    char name[50];
    int age;
    float gpa;
    int valid_input = 0;
    
    // Get and validate name
    printf("Enter student name: ");
    fgets(name, 50, stdin);
    
    // Remove trailing newline from fgets
    name[strcspn(name, "\n")] = 0;
    
    // Get and validate age
    do {
        printf("Enter student age (%d-%d): ", MIN_AGE, MAX_AGE);
        if (scanf("%d", &age) == 1) {
            if (age >= MIN_AGE && age <= MAX_AGE) {
                valid_input = 1;
            } else {
                printf("Age must be between %d and %d.\n", MIN_AGE, MAX_AGE);
            }
        } else {
            printf("Invalid input. Please enter a number.\n");
            while (getchar() != '\n');  // Clear input buffer
        }
    } while (!valid_input);
    
    // Clear input buffer
    while (getchar() != '\n');
    
    // Reset valid_input flag
    valid_input = 0;
    
    // Get and validate GPA
    do {
        printf("Enter student GPA (%.1f-%.1f): ", MIN_GPA, MAX_GPA);
        if (scanf("%f", &gpa) == 1) {
            if (gpa >= MIN_GPA && gpa <= MAX_GPA) {
                valid_input = 1;
            } else {
                printf("GPA must be between %.1f and %.1f.\n", MIN_GPA, MAX_GPA);
            }
~~~

### Operator Precedence and Associativity
Operator precedence determines the order in which operations are performed. Higher precedence operators are evaluated first.

Here's a simplified precedence table (from highest to lowest):

1. Postfix operators: `()`, `[]`, `->`, `.`, `++` (postfix), `--` (postfix)
1. Prefix operators: `++` (prefix), `--` (prefix), `+` (unary), `-` (unary), `!`, `~`, `(type)`, `*`, `&`, `sizeof`
1. Multiplicative: `*`, `/`, `%`
1. Additive: `+`, `-`
1. Shift: `<<`, `>>`
1. Relational: `<`, `<=`, `>`, `>=`
1. Equality: `==`, `!=`
1. Bitwise AND: `&`
1. Bitwise XOR: `^`
1. Bitwise OR: `|`
1. Logical AND: `&&`
1. Logical OR: `||`
1. Conditional: `?:`
1. Assignment: `=`, `+=`, `-=`, etc.
1. Comma: `,`

Example demonstrating precedence:
~~~ c
#include <stdio.h>

int main() {
    int a = 5, b = 3, c = 8, result;
    
    // Without parentheses (following precedence rules)
    result = a + b * c;
    printf("a + b * c = %d\n", result);  // 5 + (3 * 8) = 29
    
    // With parentheses (changing the order)
    result = (a + b) * c;
    printf("(a + b) * c = %d\n", result);  // (5 + 3) * 8 = 64
    
    // Complex expression
    result = a * b + c / 2 - 1;
    printf("a * b + c / 2 - 1 = %d\n", result);  // (5 * 3) + (8 / 2) - 1 = 15 + 4 - 1 = 18
    
    return 0;
}
~~~

#### 2\. `if-else` Statement
The `if-else` statement executes one block of code if a condition is true and another block if it is false.
~~~ c
if (condition) {
    // Code to execute if condition is true
} else {
    // Code to execute if condition is false
}
~~~

Example:
~~~ c
#include <stdio.h>

int main() {
    int number;
    
    printf("Enter a number: ");
    scanf("%d", &number);
    
    if (number % 2 == 0) {
        printf("%d is an even number.\n", number);
    } else {
        printf("%d is an odd number.\n", number);
    }
    
    return 0;
}
~~~
#### 3\. `if-else if-else` Ladder
The `if-else if-else` ladder checks multiple conditions in sequence.
~~~ c
if (condition1) {
    // Code to execute if condition1 is true
} else if (condition2) {
    // Code to execute if condition1 is false and condition2 is true
} else if (condition3) {
    // Code to execute if condition1 and condition2 are false and condition3 is true
} else {
    // Code to execute if all conditions are false
}
~~~

Example:

~~~ c
#include <stdio.h>

int main() {
    int score;
    
    printf("Enter your exam score (0-100): ");
    scanf("%d", &score);
    
    if (score >= 90) {
        printf("Grade: A\n");
    } else if (score >= 80) {
        printf("Grade: B\n");
~~~

## Control Structures
Control structures in C programming determine the flow of program execution. They fall into two main categories: selection structures and looping structures.
### Selection Structures
Selection structures allow a program to choose different execution paths based on conditions.
#### if Statement
The `if` statement executes a block of code if a specified condition is true.
~~~ c
#include <stdio.h>

int main() {
    int age = 20;
    
    if (age >= 18) {
        printf("You are an adult.\n");
    }
    
    return 0;
}
~~~
#### if-else Statement
The `if-else` statement provides an alternative path when the condition is false.
~~~ c
#include <stdio.h>

int main() {
    int number = 7;
    
    if (number % 2 == 0) {
        printf("%d is even.\n", number);
    } else {
        printf("%d is odd.\n", number);
    }
    
    return 0;
}
~~~
#### if-else if-else Ladder
For multiple conditions, the `if-else if-else` ladder can be used.
~~~ c
#include <stdio.h>

int main() {
    int score = 85;
    
    if (score >= 90) {
        printf("Grade: A\n");
    } else if (score >= 80) {
        printf("Grade: B\n");
    } else if (score >= 70) {
        printf("Grade: C\n");
    } else if (score >= 60) {
        printf("Grade: D\n");
    } else {
        printf("Grade: F\n");
    }
    
    return 0;
}
~~~
#### Nested if Statements
An `if` statement can be nested inside another `if` or `else` block.
~~~ c
#include <stdio.h>

int main() {
    int age = 25;
    int hasLicense = 1; // 1 for true, 0 for false
    
    if (age >= 18) {
        printf("Age requirement met.\n");
        
        if (hasLicense) {
            printf("You can drive.\n");
        } else {
            printf("You need a license to drive.\n");
        }
    } else {
        printf("You are too young to drive.\n");
    }
    
    return 0;
}
~~~
#### switch Statement
The `switch` statement provides a cleaner way to handle multiple conditions based on a single value.
~~~ c
#include <stdio.h>

int main() {
    char grade = 'B';
    
    switch (grade) {
        case 'A':
            printf("Excellent!\n");
            break;
        case 'B':
            printf("Good job!\n");
            break;
        case 'C':
            printf("Satisfactory.\n");
            break;
        case 'D':
            printf("Needs improvement.\n");
            break;
        case 'F':
            printf("Failed.\n");
            break;
        default:
            printf("Invalid grade.\n");
    }
    
    return 0;
}
~~~

**Important notes about `switch`:**

- Each `case` should end with a `break` statement to prevent fall-through.
- The `default` case handles any value not matched by the cases.
- The expression in the `switch` statement must be integral (int, char, enum).
#### Conditional Operator
The conditional operator (`? :`) provides a compact way to express simple if-else logic.
~~~ c
#include <stdio.h>

int main() {
    int age = 20;
    
    // Using conditional operator
    printf("You are %s.\n", (age >= 18) ? "an adult" : "a minor");
    
    // Equivalent if-else
    if (age >= 18) {
        printf("You are an adult.\n");
    } else {
        printf("You are a minor.\n");
    }
    
    return 0;
}
~~~
### Looping Structures
Looping structures allow a program to repeat a block of code multiple times.
#### for Loop
The `for` loop is typically used when the number of iterations is known beforehand.
~~~ c
#include <stdio.h>

int main() {
    // Print numbers from 1 to 5
    for (int i = 1; i <= 5; i++) {
        printf("%d ", i);
    }
    printf("\n");
    
    // Calculate the sum of numbers from 1 to 10
    int sum = 0;
    for (int i = 1; i <= 10; i++) {
        sum += i;
    }
    printf("Sum: %d\n", sum);
    
    return 0;
}
~~~

The `for` loop has three parts:

1. **Initialization**: Executed once before the loop starts.
1. **Condition**: Checked before each iteration; if false, the loop terminates.
1. **Update**: Executed after each iteration.
#### while Loop
The `while` loop repeats as long as a condition is true.
~~~ c
#include <stdio.h>

int main() {
    int count = 1;
    
    while (count <= 5) {
        printf("%d ", count);
        count++;
    }
    printf("\n");
    
    // Reading until a specific input
    int number;
    printf("Enter a number (0 to quit): ");
    scanf("%d", &number);
    
    while (number != 0) {
        printf("You entered: %d\n", number);
        printf("Enter another number (0 to quit): ");
        scanf("%d", &number);
    }
    
    return 0;
}
~~~
#### do-while Loop
The `do-while` loop is similar to the `while` loop, but it guarantees that the loop body executes at least once.
~~~ c
#include <stdio.h>

int main() {
    int count = 1;
    
    do {
        printf("%d ", count);
        count++;
    } while (count <= 5);
    printf("\n");
    
    // Even if the condition is initially false, the loop executes once
    int number = 10;
    
    do {
        printf("This will print once even though number > 5\n");
    } while (number <= 5);
    
    return 0;
}
~~~
#### break and continue Statements
- `break`: Exits the innermost loop immediately.
- `continue`: Skips the rest of the current iteration and moves to the next iteration.
~~~ c
#include <stdio.h>

int main() {
    // Using break to exit the loop early
    printf("Break example:\n");
    for (int i = 1; i <= 10; i++) {
        if (i == 6) {
            break; // Exit the loop when i is 6
        }
        printf("%d ", i);
    }
    printf("\n");
    
    // Using continue to skip specific iterations
    printf("Continue example:\n");
    for (int i = 1; i <= 10; i++) {
        if (i % 2 == 0) {
            continue; // Skip even numbers
        }
        printf("%d ", i);
    }
    printf("\n");
    
    return 0;
}
~~~
#### Nested Loops
Loops can be nested within other loops to handle more complex patterns.
~~~ c
#include <stdio.h>

int main() {
    // Print a pattern
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= i; j++) {
            printf("* ");
        }
        printf("\n");
    }
    
    // Print a multiplication table
    printf("\nMultiplication Table:\n");
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            printf("%d\t", i * j);
        }
        printf("\n");
    }
    
    return 0;
}
~~~

~~~ c
int main() {
~~~

~~~ c
#include <stdio.h>

int main() {
~~~

~~~ c
    char name[50];
~~~

~~~ c
    FILE *file = fopen("data.txt", "w");

    file = fopen("data.txt", "r");
~~~

~~~ c
    char str[] = "ID: 123 Score: 95.5";
~~~

## Coding Standards and Guidelines
Coding standards ensure code readability, maintainability, and consistency across projects.
### Naming Conventions

- Use meaningful names that describe the purpose.
- Follow a consistent case style (e.g., camelCase or snake\_case).
~~~ c
// Good practice
int studentCount;
float averageScore;
void calculateTotalSum();

// Bad practice
int a;
float x;
void calc();
~~~
#### Constants and Macros
- Use uppercase letters with underscores for constants and macros.
~~~ c
#define MAX_BUFFER_SIZE 1024
#define PI 3.14159

const int MIN_AGE = 18;
~~~
### Indentation and Formatting
#### Indentation
- Use consistent indentation (typically 2 or 4 spaces).
- Align braces properly.
~~~ c
// Consistent indentation example
void processData(int value) {
    if (value > 0) {
        printf("Positive value\n");
        value *= 2;
    } else {
        printf("Non-positive value\n");
        value = 0;
    }
    
    printf("Final value: %d\n", value);
}
~~~
#### Line Length
- Keep lines reasonably short (e.g., 80-120 characters).
- Break long lines logically.
~~~ c
// Long line broken into multiple lines
int result = functionWithLongName(parameter1, parameter2, 
                                 parameter3, parameter4);
                                 
// Long condition broken into multiple lines
if (condition1 && 
    condition2 && 
    condition3) {
    // Code block
}
~~~
### Comments and Documentation
#### Function Comments
- Document function purpose, parameters, and return values.
~~~ c
/**
 * Calculates the average of an array of integers.
 *
 * @param arr The input array
 * @param size The size of the array
 * @return The average of the elements
 */
float calculateAverage(int arr[], int size) {
    if (size <= 0) {
        return 0.0f;
    }

    }

}
~~~

## Arrays - 1D, Initialization and Traversal
Arrays are collections of elements of the same type stored in contiguous memory locations.
### Declaration and Initialization
#### Array Declaration
~~~ c
// Declaration without initialization
int numbers[5]; // Array of 5 integers

// Declaration with size determined by the compiler
int days[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
~~~
#### Array Initialization
~~~ c
#include <stdio.h>

int main() {
    // Initialize at declaration
    int scores[5] = {95, 88, 76, 90, 82};
    
    // Partial initialization (remaining elements are set to 0)
    int values[5] = {10, 20};  // Equivalent to {10, 20, 0, 0, 0}
    
    // Initialize all elements to zero
    int zeros[10] = {0};
    
    // Initialize after declaration
    int grades[3];
    grades[0] = 85;
    grades[1] = 92;
    grades[2] = 78;
    
    return 0;
}
~~~
### Accessing and Modifying Elements
~~~ c
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    
    // Accessing elements
    printf("First element: %d\n", numbers[0]);
    printf("Third element: %d\n", numbers[2]);
    
    // Modifying elements
    numbers[1] = 25;
    numbers[4] = 55;
    
    // Displaying all elements
    printf("Updated array: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");
    
    return 0;
}
~~~
### Array Traversal Techniques
#### Using for Loop
~~~ c
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int sum = 0;
    
    // Simple traversal
    printf("Array elements: ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", numbers[i]);
    }
    printf("\n");
    
    // Traversal with calculation
    for (int i = 0; i < 5; i++) {
        sum += numbers[i];
    }
    printf("Sum of elements: %d\n", sum);
    
    // Reverse traversal
    printf("Array in reverse: ");
    for (int i = 4; i >= 0; i--) {
        printf("%d ", numbers[i]);
    }
    printf("\n");
    
    return 0;
}
~~~
#### Using while Loop
~~~ c
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int i = 0;
    
    printf("Array elements (using while): ");
    while (i < 5) {
        printf("%d ", numbers[i]);
        i++;
    }
    printf("\n");
    
    return 0;
}
~~~
#### Using Pointers
~~~ c
#include <stdio.h>

int main() {
    int numbers[5] = {10, 20, 30, 40, 50};
    int *ptr = numbers; // Pointer to the first element
    
    printf("Array elements (using pointer): ");
    for (int i = 0; i < 5; i++) {
        printf("%d ", *(ptr + i));
    }
    printf("\n");
    
    // Alternative pointer traversal
    printf("Array elements (using pointer arithmetic): ");
    for (int *p = numbers; p < numbers + 5; p++) {
        printf("%d ", *p);
    }
    printf("\n");
    
    return 0;
}
~~~

### Common 2D Array Operations

~~~ c
#include <stdio.h>

int main() {
~~~

#### Matrix Multiplication
~~~ c
#include <stdio.h>

int main() {
    int A[2][3] = {{1, 2, 3}, {4, 5, 6}};
    int B[3][2] = {{7, 8}, {9, 10}, {11, 12}};
    int C[2][2] = {0}; // To store the result, initialized to zeros
    
    // Multiply matrices A and B
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            for (int k = 0; k < 3; k++) {
                C[i][j] += A[i][k] * B[k][j];
            }
        }
    }
    
    // Display the result
    printf("Matrix Multiplication Result:\n");
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 2; j++) {
            printf("%3d ", C[i][j]);
        }
        printf("\n");
    }
    
    return 0;
}
~~~
#### Finding the Sum of Diagonals
~~~ c
#include <stdio.h>

int main() {
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 5, 6},
        {7, 8, 9}
    };
    
    int mainDiagonalSum = 0;
    int antiDiagonalSum = 0;
    
    for (int i = 0; i < 3; i++) {
        mainDiagonalSum += matrix[i][i];            // Main diagonal
        antiDiagonalSum += matrix[i][3 - 1 - i];    // Anti-diagonal
    }
    
    printf("Main Diagonal Sum: %d\n", mainDiagonalSum);
    printf("Anti-Diagonal Sum: %d\n", antiDiagonalSum);
    
    return 0;
}
~~~

~~~ c
    int *p1 = &numbers[1];
~~~

### Parameter Passing
#### Pass by Value
In C, all parameters are passed by value, meaning a copy of the argument is passed to the function.
~~~ c
#include <stdio.h>

    x = x * 2;  // Modifies the local copy, not the original
    printf("Inside function: x = %d\n", x);
}

int main() {
    int num = 10;
    
    printf("Before function call: num = %d\n", num);

    return 0;
}
~~~

To modify the original value, pass a pointer to the variable.

~~~ c
}

    int num = 10;
    
    printf("Before function call: num = %d\n", num);
    modifyValue(&num);  // Pass the address of num
~~~

## Storage Classes
Storage classes in C determine the scope, lifetime, and initialization of variables.
### auto Storage Class
The `auto` storage class is the default for local variables. Variables are automatically created at the beginning of a block and destroyed at the end.
~~~ c
#include <stdio.h>

void demoAutoStorage() {
    auto int x = 10;  // 'auto' is optional, as it's the default
    printf("Inside function: x = %d\n", x);
}

int main() {
    int y = 20;  // 'auto' is implied
    {
        auto int z = 30;
        printf("Inside block: y = %d, z = %d\n", y, z);
    }
    // z is no longer accessible here
    
    demoAutoStorage();
    // x from demoAutoStorage() is not accessible here
    
    return 0;
}
~~~

### register Storage Class
The `register` storage class suggests the compiler to store the variable in a CPU register for faster access. However, modern compilers optimize well, so this is often unnecessary.
~~~ c

    cpu_time_used = ((double) (end - start)) / CLOCKS_PER_SEC;
    
    printf("Sum: %d\n", sum);
    printf("Time taken: %f seconds\n", cpu_time_used);
    
    return 0;
~~~

## Introduction to Recursion
Recursion is a programming technique where a function calls itself to solve a problem. The solution to a complex problem is expressed in terms of simpler instances of the same problem.
### Key Components of Recursion:
1. **Base Case**: The condition that stops the recursion
1. **Recursive Case**: The part where the function calls itself
### Basic Syntax of a Recursive Function in C:
~~~ c
return_type function_name(parameters) {
    // Base case
    if (base_case_condition) {
        return base_case_value;
    }
    // Recursive case
    else {
        // Process data and make recursive call(s)
        return function_name(modified_parameters);
    }
}
~~~
### Example: Factorial Calculation
~~~ c
#include <stdio.h>

// Recursive function to calculate factorial
unsigned long factorial(unsigned int n) {
    // Base case
    if (n == 0 || n == 1) {
        return 1;
    }
    // Recursive case
    else {
        return n * factorial(n - 1);
    }
}

int main() {
    unsigned int number = 5;
    printf("Factorial of %u is %lu\n", number, factorial(number));
    return 0;
}
~~~

Output:
~~~
Factorial of 5 is 120
~~~

In this example:

- The base case is when `n` equals 0 or 1, where the factorial is 1.
- The recursive case calculates `n * factorial(n-1)`.
### Memory Stack During Recursion
Understanding what happens in memory is crucial:

For `factorial(5)`:

1. Call `factorial(5)` → Waits for `factorial(4)`
1. Call `factorial(4)` → Waits for `factorial(3)`
1. Call `factorial(3)` → Waits for `factorial(2)`
1. Call `factorial(2)` → Waits for `factorial(1)`
1. Call `factorial(1)` → Returns 1 (base case)
1. `factorial(2)` completes: 2 \* 1 = 2
1. `factorial(3)` completes: 3 \* 2 = 6
1. `factorial(4)` completes: 4 \* 6 = 24
1. `factorial(5)` completes: 5 \* 24 = 120
### Recursion vs. Iteration
Recursion often provides a more elegant and natural solution for certain problems, but it comes with a cost:

|Aspect|Recursion|Iteration|
| :-: | :-: | :-: |
|Memory|Higher (stack space)|Lower|
|Speed|Generally slower|Generally faster|
|Clarity|Often clearer for certain problems|Can be more complex for the same problems|
|Stack Overflow|Risk exists|No risk|

## Searching Algorithms
Searching is the process of finding a specific element within a collection of data. Let's implement the two most common searching algorithms.
### Linear Search
Linear search sequentially checks each element until the target is found or the end is reached.
~~~ c
#include <stdio.h>

// Recursive linear search
int recursiveLinearSearch(int arr[], int size, int target, int currentIndex) {
    // Base cases
    if (currentIndex >= size) {  // Element not found
        return -1;
    }
    if (arr[currentIndex] == target) {  // Element found
        return currentIndex;
    }
    
    // Recursive case
    return recursiveLinearSearch(arr, size, target, currentIndex + 1);
}

// Iterative linear search
int iterativeLinearSearch(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return i;  // Return index of the found element
        }
    }
    return -1;  // Element not found
}

int main() {
    int arr[] = {12, 34, 54, 2, 3};
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 3;
    
    // Using recursive linear search
    int recResult = recursiveLinearSearch(arr, size, target, 0);
    if (recResult != -1) {
        printf("Recursive Linear Search: Element found at index %d\n", recResult);
    } else {
        printf("Recursive Linear Search: Element not found\n");
    }
    
    // Using iterative linear search
    int iterResult = iterativeLinearSearch(arr, size, target);
    if (iterResult != -1) {
        printf("Iterative Linear Search: Element found at index %d\n", iterResult);
    } else {
        printf("Iterative Linear Search: Element not found\n");
    }
    
    return 0;
}
~~~

### Binary Search
Binary search is much faster than linear search for sorted arrays, with O(log n) time complexity.
~~~ c
#include <stdio.h>

// Recursive binary search
int recursiveBinarySearch(int arr[], int low, int high, int target) {
    // Base case
    if (low > high) {
        return -1;  // Element not found
    }
    
    // Calculate middle index
    int mid = low + (high - low) / 2;
    
    // Found the element
    if (arr[mid] == target) {
        return mid;
    }
    
    // Recursive cases
    // Search in the left half
    if (arr[mid] > target) {
        return recursiveBinarySearch(arr, low, mid - 1, target);
    }
    
    // Search in the right half
    return recursiveBinarySearch(arr, mid + 1, high, target);
}

// Iterative binary search
int iterativeBinarySearch(int arr[], int size, int target) {
    int low = 0;
    int high = size - 1;
    
    while (low <= high) {
        int mid = low + (high - low) / 2;
        
        // Check if target is present at mid
        if (arr[mid] == target) {
            return mid;
        }
        
        // If target is greater, ignore left half
        if (arr[mid] < target) {
            low = mid + 1;
        }
        // If target is smaller, ignore right half
        else {
            high = mid - 1;
        }
    }
    
    return -1;  // Element not found
}

int main() {
    int arr[] = {2, 3, 12, 34, 54, 65, 78};  // Must be sorted for binary search
    int size = sizeof(arr) / sizeof(arr[0]);
    int target = 34;
    
    // Using recursive binary search
    int recResult = recursiveBinarySearch(arr, 0, size - 1, target);
    if (recResult != -1) {
        printf("Recursive Binary Search: Element found at index %d\n", recResult);
    } else {
        printf("Recursive Binary Search: Element not found\n");
    }
    
    // Using iterative binary search
    int iterResult = iterativeBinarySearch(arr, size, target);
    if (iterResult != -1) {
        printf("Iterative Binary Search: Element found at index %d\n", iterResult);
    } else {
        printf("Iterative Binary Search: Element not found\n");
    }
    
    return 0;
}
~~~

## Sorting Algorithms
Sorting arranges elements in a specific order. Let's implement several common sorting algorithms using both recursive and iterative approaches.
### Quick Sort (Recursive)
Quick sort is an efficient, divide-and-conquer sorting algorithm with an average time complexity of O(n log n).
~~~ c
#include <stdio.h>

// Function to swap two elements
void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// Function to partition the array
int partition(int arr[], int low, int high) {
    int pivot = arr[high];  // Select the rightmost element as pivot
    int i = (low - 1);      // Index of smaller element
    
    for (int j = low; j <= high - 1; j++) {
        // If current element is smaller than or equal to pivot
        if (arr[j] <= pivot) {
            i++;  // Increment index of smaller element
            swap(&arr[i], &arr[j]);
        }
    }
    swap(&arr[i + 1], &arr[high]);
    return (i + 1);
}

// Recursive QuickSort function
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        // pi is the partitioning index
        int pi = partition(arr, low, high);
        
        // Sort elements before and after partition
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

// Function to print an array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {10, 7, 8, 9, 1, 5};
    int size = sizeof(arr) / sizeof(arr[0]);
    
    printf("Original array: ");
    printArray(arr, size);
    
    quickSort(arr, 0, size - 1);
    
    printf("Sorted array: ");
    printArray(arr, size);
    
    return 0;
}
~~~

Sorted array: 1 5 7 8 9 10

### Merge Sort (Recursive)
Merge sort is a stable, divide-and-conquer algorithm with a time complexity of O(n log n).
~~~ c
#include <stdio.h>
#include <stdlib.h>

// Merge two subarrays of arr[]
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1;
    int n2 = right - mid;
    
    // Create temporary arrays
    int *L = (int*)malloc(n1 * sizeof(int));
    int *R = (int*)malloc(n2 * sizeof(int));
    
    // Copy data to temporary arrays
    for (i = 0; i < n1; i++) {
        L[i] = arr[left + i];
    }
    for (j = 0; j < n2; j++) {
        R[j] = arr[mid + 1 + j];
    }
    
    // Merge temporary arrays back into arr[left..right]
    i = 0;      // Initial index of first subarray
    j = 0;      // Initial index of second subarray
    k = left;   // Initial index of merged subarray
    
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i];
            i++;
        } else {
            arr[k] = R[j];
            j++;
        }
        k++;
    }
    
    // Copy remaining elements of L[] if any
    while (i < n1) {
        arr[k] = L[i];
        i++;
        k++;
    }
    
    // Copy remaining elements of R[] if any
    while (j < n2) {
        arr[k] = R[j];
        j++;
        k++;
    }
    
    // Free the allocated memory
    free(L);
    free(R);
}

// Recursive merge sort function
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        // Find the middle point
        int mid = left + (right - left) / 2;
        
        // Sort first and second halves
        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        
        // Merge the sorted halves
        merge(arr, left, mid, right);
    }
}

// Function to print an array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {12, 11, 13, 5, 6, 7};
    int size = sizeof(arr) / sizeof(arr[0]);
    
    printf("Original array: ");
    printArray(arr, size);
    
    mergeSort(arr, 0, size - 1);
    
    printf("Sorted array: ");
    printArray(arr, size);
    
    return 0;
}
~~~

Sorted array: 5 6 7 11 12 13

### Bubble Sort (Recursive)
Bubble sort is a simple comparison-based algorithm. Here's a recursive implementation:
~~~ c
#include <stdio.h>

// A recursive function for bubble sort
void recursiveBubbleSort(int arr[], int n) {
    // Base case
    if (n == 1) {
        return;
    }
    
    // One pass of bubble sort. After this pass, the largest element is moved to the end
    int swapped = 0;
    for (int i = 0; i < n - 1; i++) {
        if (arr[i] > arr[i + 1]) {
            // Swap arr[i] and arr[i+1]
            int temp = arr[i];
            arr[i] = arr[i + 1];
            arr[i + 1] = temp;
            swapped = 1;
        }
    }
    
    // If no swapping occurred in this pass, array is sorted
    if (swapped == 0) {
        return;
    }
    
    // Largest element is fixed, recur for remaining array
    recursiveBubbleSort(arr, n - 1);
}

// Function to print an array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int size = sizeof(arr) / sizeof(arr[0]);
    
    printf("Original array: ");
    printArray(arr, size);
    
    recursiveBubbleSort(arr, size);
    
    printf("Sorted array: ");
    printArray(arr, size);
    
    return 0;
}
~~~

### Callbacks for Searching

~~~ c
#include <stdio.h>

// A search function that uses a callback to determine if an element matches
int findElement(int arr[], int size, int (*matchFunc)(int, int), int key) {
    for (int i = 0; i < size; i++) {
        if (matchFunc(arr[i], key)) {
            return i;  // Return index if element is found
        }
    }
    return -1;  // Return -1 if element is not found
}

// Callback for exact match
int exactMatch(int element, int key) {
    return element == key;
}

// Callback for finding elements greater than key
int greaterThan(int element, int key) {
    return element > key;
}

// Callback for finding even elements
int isEven(int element, int key) {
    // Key is ignored in this callback
    return element % 2 == 0;
}

int main() {
    int arr[] = {5, 12, 7, 20, 15, 8};
    int size = sizeof(arr) / sizeof(arr[0]);
    
    // Find exact match for 7
    int index = findElement(arr, size, exactMatch, 7);
    if (index != -1) {
        printf("Element 7 found at index: %d\n", index);
    } else {
        printf("Element 7 not found\n");
    }
    
    // Find first element greater than 10
    index = findElement(arr, size, greaterThan, 10);
    if (index != -1) {
        printf("First element greater than 10 found at index %d with value %d\n", index, arr[index]);
    } else {
        printf("No element greater than 10 found\n");
    }
    
    // Find first even element
    index = findElement(arr, size, isEven, 0); // Key is ignored in isEven
    if (index != -1) {
        printf("First even element found at index %d with value %d\n", index, arr[index]);
    } else {
        printf("No even element found\n");
    }
    
    return 0;
}
~~~

~~~ c
// A generic bubble sort function that uses a callback to determine sort order
void bubbleSort(int arr[], int size, int (*compare)(int, int)) {
    for (int i = 0; i < size - 1; i++) {
        for (int j = 0; j < size - i - 1; j++) {
            // If compare function returns true, swap the elements
            if (compare(arr[j], arr[j + 1])) {
                swap(&arr[j], &arr[j + 1]);
            }
        }
    }
}

// Callback for ascending order
int ascending(int a, int b) {
    return a > b;
}

// Callback for descending order
int descending(int a, int b) {
    return a < b;
}

// Callback for even-first ordering (even numbers before odd numbers)
int evenFirst(int a, int b) {
    // If a is odd and b is even, swap them
    if (a % 2 != 0 && b % 2 == 0) {
        return 1;
    }
    // If both are even or both are odd, maintain original order
    else if ((a % 2 == 0 && b % 2 == 0) || (a % 2 != 0 && b % 2 != 0)) {
        return a > b;  // Sort in ascending order within the same parity
    }
    // If a is even and b is odd, keep them as is
    return 0;
}

// Function to print an array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int size = sizeof(arr) / sizeof(arr[0]);
    int arrCopy1[size], arrCopy2[size];
    
    // Copy original array to preserve it for multiple sorts
    for (int i = 0; i < size; i++) {
        arrCopy1[i] = arr[i];
        arrCopy2[i] = arr[i];
    }
    
    printf("Original array: ");
    printArray(arr, size);
    
    // Sort in ascending order
    bubbleSort(arr, size, ascending);
    printf("Sorted in ascending order: ");
    printArray(arr, size);
    
    // Sort in descending order
    bubbleSort(arrCopy1, size, descending);
    printf("Sorted in descending order: ");
    printArray(arrCopy1, size);
    
    // Sort by even-first rule
    bubbleSort(arrCopy2, size, evenFirst);
    printf("Sorted with even numbers first: ");

    return 0;
}
~~~

### Advanced Example: Map-Reduce with Callbacks
Let's implement a simple Map-Reduce pattern using callbacks:
~~~ c
#include <stdio.h>
#include <stdlib.h>

// Map function: applies a transformation to each element in an array
int* mapArray(int arr[], int size, int (*transform)(int)) {
    int* result = (int*)malloc(size * sizeof(int));
    for (int i = 0; i < size; i++) {
        result[i] = transform(arr[i]);
    }
    return result;
}

// Reduce function: reduces an array to a single value using an accumulator
int reduceArray(int arr[], int size, int (*combine)(int, int), int initialValue) {
    int accumulator = initialValue;
    for (int i = 0; i < size; i++) {
        accumulator = combine(accumulator, arr[i]);
    }
    return accumulator;
}

// Transform functions for map
int square(int x) {
    return x * x;
}

int double_value(int x) {
    return x * 2;
}

int absolute(int x) {
    return x < 0 ? -x : x;
}

// Combine functions for reduce
int sum(int acc, int value) {
    return acc + value;
}

int product(int acc, int value) {
    return acc * value;
}

int max(int acc, int value) {
    return acc > value ? acc : value;
}

// Function to print an array
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

    printArray(arr, size);

    int* squares = mapArray(arr, size, square);

    int* doubles = mapArray(arr, size, double_value);
    printf("Doubled values: ");
    printArray(doubles, size);
    
    int* absolutes = mapArray(arr, size, absolute);
    printf("Absolute values: ");
    printArray(absolutes, size);
    
    // Reduce examples
    printf("Sum of elements: %d\n", reduceArray(arr, size, sum, 0));

    // Combine map and reduce
~~~

## Common Pitfalls and Best Practices
### Recursion Pitfalls
1. **Stack Overflow**: Recursive functions can cause stack overflow if there are too many recursive calls or if the base case is not properly defined.
   ~~~ c
   // Dangerous recursion - may cause stack overflow
   int dangerous_recursion(int n) {
       // Missing or incorrect base case
       return n + dangerous_recursion(n - 1);
   }
   ~~~
1. **Inefficient Repeated Calculations**: As seen in the naive Fibonacci implementation, recursion can lead to many redundant calculations.
1. **Memory Usage**: Each recursive call adds a new layer to the call stack, consuming memory.
### Best Practices for Recursion
1. **Always Define a Proper Base Case**: Ensure there's always a way to terminate the recursion.
   ~~~ c
   int safe_recursion(int n) {
       // Proper base case
       if (n <= 0) {
           return 0;
       }
       return n + safe_recursion(n - 1);
   }
   ~~~
1. **Consider Tail Recursion**: Tail recursion can be optimized by many compilers.
   ~~~ c
   // Tail-recursive factorial function
   unsigned long factorial_tail(unsigned int n, unsigned long accumulator) {
       if (n == 0 || n == 1) {
           return accumulator;
       }
       return factorial_tail(n - 1, n * accumulator);
   }

   // Wrapper function
   unsigned long factorial(unsigned int n) {
       return factorial_tail(n, 1);
   }
   ~~~
1. **Use Memoization for Expensive Calculations**: Store results of subproblems to avoid redundant calculations.
   ~~~ c
   #include <stdio.h>
   #include <stdlib.h>

   // Fibonacci with memoization
   int fibonacci_memo(int n, int* memo) {
       // Base cases
       if (n <= 0) return 0;
       if (n == 1) return 1;
    
       // Check if already computed
       if (memo[n] != -1) {
           return memo[n];
       }
    
       // Compute and store
       memo[n] = fibonacci_memo(n - 1, memo) + fibonacci_memo(n - 2, memo);
       return memo[n];
   }

   int fibonacci(int n) {
       // Initialize memoization array
       int* memo = (int*)malloc((n + 1) * sizeof(int));
       for (int i = 0; i <= n; i++) {
           memo[i] = -1;
       }
    
       int result = fibonacci_memo(n, memo);
       free(memo);
       return result;
   }
   ~~~
1. **Consider Iterative Alternatives**: For some problems, an iterative solution might be more efficient.
### Callback Best Practices
1. **Type Safety**: Use typedefs for callback function pointers to improve clarity and safety.
   ~~~ c
   typedef int (*ComparisonFunction)(int, int);

   void bubbleSort(int arr[], int size, ComparisonFunction compare) {
       // Implementation
   }
   ~~~
1. **Error Handling**: Check if callback functions are valid before using them.
   ~~~ c
   void safeFunction(int arr[], int size, int (*callback)(int)) {
       if (callback == NULL) {
           printf("Error: Null callback function\n");
           return;
       }
       // Use callback
   }
   ~~~
1. **Context Data**: Pass additional context data to callbacks when needed.
   ~~~ c
   typedef struct {
       // Context data
       int threshold;
       int multiplier;
   } Context;

   int transformWithContext(int value, Context* ctx) {
       if (value > ctx->threshold) {
           return value * ctx->multiplier;
       }
       return value;
   }

   void processWithContext(int arr[], int size, int (*transform)(int, Context*), Context* ctx) {
       for (int i = 0; i < size; i++) {
           arr[i] = transform(arr[i], ctx);
       }
   }
   ~~~
